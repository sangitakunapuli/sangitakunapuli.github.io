# Sangita Kunapuli

Source for my personal portfolio, built with Astro.

## Local development

Use Node 22 (the version is pinned in `.nvmrc`). With nvm installed:

```sh
nvm use
npm install
npm run dev
```

Open the local address printed in the terminal. Run `npm run build` to check types and create the static site in `dist/`.

Project descriptions, experience, navigation, and social links are in `src/config/index.ts`. Screenshots are in `public/`. The gallery, cube, and timeline interactions are in `src/scripts/`.
